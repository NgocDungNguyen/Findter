# Tone and copy

Matches Shopify's Polaris content guidelines and BFS 4.2.1 / 4.3.

## Voice

- Clear, calm, helpful. Talk to the merchant as "you". Plain words; no jargon, hype or exclamation marks.
- Short and scannable: headings 2–5 words, one-sentence descriptions, no multi-paragraph blocks (BFS 4.3.4 #3).
- Be specific about what happens and about units ("Switch banners every (seconds)").
- Never promise results: say what a feature **does**, not what the merchant will earn ("Shows relevant filters on collection pages", not "Boost sales by 30%") (BFS 4.3.1).
- No pressure: no urgency words, countdowns, guilt wording, or incentives for reviews (BFS 4.3.2).

## Mechanics

- **Sentence case** for headings, buttons, labels, tabs, nav ("Add filter set", not "Add Filter Set").
- Buttons start with a verb: Add, Save, Edit, Delete, Enable, Discard, Preview.
- Numbers as digits; units spelled once and consistently; dates "Jan 5, 2026"; times with a clear time zone when it matters.
- Oxford comma; no "&" in running text (the nav label "Filter & product grid design" is the existing app's name for a nav item only).
- No emojis in the UI. No ALL CAPS.
- Spell-check every heading, nav item and button (BFS 4.2.1 #1).

## Message patterns

| Situation | Pattern | Example |
|---|---|---|
| Success toast | Past tense, 1–3 words | "Saved" · "Banner added" |
| Inline error | What is wrong + how to fix | "Enter a link that starts with https://" |
| Destructive confirm | Title is a question; body states the consequence | "Delete this banner?" / "It will no longer show on the homepage." |
| Empty state | Heading + reason + action | "No filter sets yet" / "Create a filter set to show filters on your collections." / **Add filter set** |
| Unsaved changes | Direct and neutral | "You have unsaved changes. Leave without saving?" / **Save**, Discard |
| Plan-gated feature | Name the plan and link to upgrade | "Available on the Advanced plan. Upgrade" |
| Onboarding step | Title + why it matters + one button | "Add the filter block to your theme" / "Shoppers will see filters on collection pages." / **Open theme editor** |
| Asking for merchant info | Always say why | "We'll use this to recommend the right layout." |

## Words to prefer / avoid

| Prefer | Avoid |
|---|---|
| Save, Discard | Submit, Cancel changes |
| Delete (permanent) / Remove (reversible) | Destroy, Trash |
| Turn on / Turn off, Enable / Disable (toggle labels) | Activate/Deactivate mixed with Enable |
| Merchant (internal), "you" (UI) | User, Customer (for merchants) |
| Storefront, online store | Website, frontend |
| Set up | Setup (as verb) |

## Promotion copy

- Descriptive and honest, never comparative or guaranteed. Promoted apps show their real rating (BFS 4.3.1 #2). Every promo is dismissible and stays dismissed (4.3.6).
